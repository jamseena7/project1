# Hospital Patient Satisfaction Analysis Dashboard | Microsoft Excel

An interactive Excel dashboard developed to analyse hospital patient satisfaction, patient visits, and waiting times.

This project uses Microsoft Excel features such as Pivot Tables, Pivot Charts, Slicers, and KPI cards to transform raw healthcare data into meaningful insights.

![Uploading Screenshot 2026-11-24 190605.png…]()


### Key Features
- Patient satisfaction analysis
- Average waiting time analysis
- Patient visit trends
- Department-wise performance analysis
- Interactive filters using slicers
- KPI tracking and data visualization

### Tools & Technologies
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers
- Data Cleaning
- Dashboard Design
- Data Visualization

### Project Objective
To analyse healthcare service performance, identify patient satisfaction trends, and provide data-driven insights that can support better decision-making and improve patient experience.

**Skills Demonstrated:** Data Analysis | Data Visualization | Excel | Dashboard Development | Business Insights
